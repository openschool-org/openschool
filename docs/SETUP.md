# Setting up OpenSchool

Setup comes in two parts:

1. **[Server setup](./setup/server.md)** - install and run the stack
   (Postgres, ThunderID, backend, frontend), configure email and the
   environment, and prepare a production server: TLS, secrets, backups and
   restore.
2. **[School setup](./setup/school.md)** - in the running app: register the
   first admin, run the school wizard, then add teachers and students, set
   up timetables, notifications and parent access.

ThunderID itself is configured once, see [`THUNDERID.md`](./THUNDERID.md).
